# Warehouse Live BI Dashboard (Prototype)

Static mockup of a live BI dashboard for warehouse operations.

## Purpose
- visualize backlog
- monitor SLA risk
- track expedition flow
- overview of inbound, outbound and capacity

## Scope
This is a static prototype with mocked data.
No real data connection, no backend.

## Structure
- Overview – high-level warehouse health
- Backlog – active orders and stock transfers
- Active Tasks – workload per activity
- Delay / SLA – SLA performance
- Expedition & Last Mile – shipping and carriers
- Inbound Speed – receiving performance
- Efficiency – productivity metrics
- User Management – capacity and workload

## Notes
- No targets or root cause analysis included yet
- Dashboard shows only raw operational values
